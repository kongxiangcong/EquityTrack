# 01 — 保护金融量纲与统一股权桥

**What to build:** 让用户在运行现有 DCF、同业和历史估值时得到单位、倍率、期间、币种和价值口径均可复核的结果；合法旧样例保持兼容，任何混用“元/百万元”“股/万股”、跨期或重复桥接的输入在形成每股价值前明确受阻。

**Blocked by:** None — can start immediately.

**Status:** done

- [x] 所有进入正式估值的金融数量使用 exact decimal，并显式携带单位、倍率、币种、期间、截至时点及 Fact/Assumption 引用。
- [x] 企业价值方法只通过一个统一股权桥处理现金、债务、租赁、优先股、少数股东、养老金、联营价值、非经营资产、稀释和 FX；股权价值方法不会重复扣减净债务。
- [x] 有效的现有 DCF、同业和历史估值 worked examples 结果保持不变，旧请求通过兼容 adapter 运行。
- [x] 单位、倍率、币种、期间、股数或价值基础不一致时返回稳定的方法级受阻诊断，不静默换算或补零。
- [x] canonical 输出和计算 trace 可重算且不含 binary float；研究核心与平台回归保持通过。
