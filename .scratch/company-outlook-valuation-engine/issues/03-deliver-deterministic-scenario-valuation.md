# 03 — 交付多方法确定性情景估值

**What to build:** 让用户看到基准、改善和压力等内部一致的经营情景如何改变财务结果、不同估值方法和条件每股价值，而不是只看到静态情景卡或单一点值。

**Blocked by:** 01 — 保护金融量纲与统一股权桥; 02 — 建立类型化 Forecast 故事图.

**Status:** done

- [x] 每个情景由一组相互一致的 Driver overrides 形成，并重新计算财务预测、股权桥和方法级 Valuation。
- [x] 普通多分部路径至少可执行 FCFF、SOTP、reverse DCF，并复用受证据门禁保护的同业与历史估值带。
- [x] 方法结果统一返回适用性、价值基础、期限、假设、公式版本、条件价值区间、敏感性、诊断和 lineage。
- [x] 无概率依据时只展示条件情景；只有口径、期限、桥接和权重依据可比较时才允许综合，多方法默认并列三角验证。
- [x] 任一方法受阻只禁用该方法，基础研究、Forecast 和其他可用方法继续交付。
