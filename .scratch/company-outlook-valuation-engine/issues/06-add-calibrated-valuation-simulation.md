# 06 — 增加校准后的 Valuation 模拟

**What to build:** 让用户在确定性情景之外看到由业务不确定性驱动的条件每股价值分布、尾部风险和关键变量贡献，同时能判断分布依据和模拟是否收敛。

**Blocked by:** 03 — 交付多方法确定性情景估值; 04 — 持久化不可变 Forecast 与 Valuation 产物.

**Status:** ready-for-agent

- [ ] 每个随机 Assumption 显式保存分布族、参数、硬边界、校准样本/窗口、截至时点、依据和用户覆盖身份；系统不提供无依据的默认正态分布。
- [ ] 相关性/依赖模型版本化并校验对称、单位对角和半正定；非法结构 fail closed，不静默修复。
- [ ] Simulation 保存 RNG 算法、seed、样本预算、批次、约束路径、无效路径率、收敛容差和连续稳定批次数；相同输入与版本逐字节可复现。
- [ ] 只有收敛通过时发布 P5/P25/P50/P75/P95、尾部结果和适用于相关输入的贡献度；否则保留确定性情景并标记模拟受限。
- [ ] 线性 toy model、相关样本、重尾/不足样本和非法经营路径均有独立真值或性质测试。
