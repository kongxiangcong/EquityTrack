# 07 — 独立建模市场价格路径

**What to build:** 让用户在不混淆内在价值的前提下，查看特定市场状态下未来价格/收益路径、最大回撤和触发概率的研究分布，并理解它与基本面价值分布之间的差异。

**Blocked by:** 04 — 持久化不可变 Forecast 与 Valuation 产物; 06 — 增加校准后的 Valuation 模拟.

**Status:** done

- [x] 价格路径模型使用 PIT 合法、复权语义明确的历史序列和市场状态；默认评估区块自助或状态条件分布，不无解释套 IID 正态或 GBM。
- [x] 路径结果与 Valuation 分布使用不同 artifact kind、假设、版本和解释，不把模拟终点价格称作内在价值或目标价。
- [x] 输出期限收益、回撤、阈值触发和尾部概率，并保存成本、停牌/涨跌停等适用市场限制。
- [x] 前视、同收盘成交、未来状态标签、公司行动和样本窗口泄漏均有失败测试。
- [x] 报告并列解释价值背离与市场路径不确定性，但不生成个性化交易动作。
