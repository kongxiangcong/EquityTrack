# 11 — 支持创新药 rNPV 与 SOTP

**What to build:** 让临床前或尚未商业化的生物医药证券按资产、适应症、阶段、权益归属、里程碑、研发成本和现金 runway 推演，而不是用普通 DCF 或把技术储备按百分百成功计价。

**Blocked by:** 03 — 交付多方法确定性情景估值; 04 — 持久化不可变 Forecast 与 Valuation 产物.

**Status:** ready-for-agent

- [ ] 路由识别 pre-revenue / pipeline-driven 结构，选择 rNPV/SOTP 和 cash-runway，禁用不适用的普通 FCFF。
- [ ] 每个资产/适应症保存阶段、PoS 依据、开发时间、成本、里程碑、分成、权益和商业情景，并避免跨资产重复计价。
- [ ] 事件树处理临床、监管和商业里程碑，概率只在来源与校准可审计时使用。
- [ ] 现金 runway、融资和稀释进入股权价值桥；技术储备不会自动变成成熟收入或满概率价值。
- [ ] worked examples 覆盖资产失败、延迟、授权变化、稀释和相关事件依赖。
