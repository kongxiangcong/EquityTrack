第一篇：多氟多的缺点

今天还没开盘，先聊一下多氟多的缺点。提前给接下来的行情要带来的心理变化降一下温度。
1.  持股比例太低。 意味着跟公司齐心的程度低一些。可以通过某些运作就能额外得到钱，而不是做好公司通过分红等得到更多。当然，这只是暗地的风险，并不是一定如此。从我搜集到的各位老多多投资者来说，有人有担忧，好产业留给儿子女儿，并不在上市公司里，这点持股比例，会不会直接在经营中日常输送给他们？这块是个忧虑点。他们喜欢玩自家那些股票，高抛低吸，其实这点无可厚非，我甚至觉得是个好事。
2.  多元化经营。 多元化经营这事得双面看。对于企业来说，是绝对的好事，多多技术强悍，多元化经营是有优势的，电池（负极，电解液，隔膜），氢氟酸（半导体从没跟过），硼同位素（医疗，核，都没炒过），六氟反而是一直热炒的。多元化经营意味着，他们一定是经常探索方向的，而这个探索，必然会有失败。比如15年前后收购红星汽车后续退出，有造车的野心，但是实力不允许，这个亏了不少，再比如收购某个萤石矿又卖了，也亏了一些。这些会被当成"瞎投资"。我觉得会是损失，当然，对于高管来说，这些是不可缺少的教训。这次做电池的策略就做的很好，步子比较小，对公司的负面冲击减轻了很多，这次能拿出来正面战场硬刚，也是在以往的教训中得到的经验吧。也有些公司一次all in然后市值快速壮大的，走的就比多氟多快的很多，有的拜码头和大客户绑定，也走的很快，这个事的劣势也会很明显，对于企业来说，上升期是好事，但是，总有落寞期的。
3.  周期。 虽然他们李家一直不认可自己是周期股的事实，上一轮60多的时候吹能到80，最后回落了很久，然后循环。多多想要对抗周期的办法，就是多元，在各个期间抵御风险，保持平稳切换重心。股价涨停的几率比较低，持股分散难形成合力，所以很多时候股价上涨短期内不如另外两家，当然，拉长了看，还是可以的。上一轮锁量锁价策略，让公司少赚了非常多钱，这个策略让上轮周期的时候没能干赢。本轮幸好只有30%的长协单到年底。希望本轮周期多多能把六氟的红利吃到嘴吧。
4.  搞技术的，如何转变为市值。 李家那几个掌舵者信奉的是，把一件事做到极致，奇迹自然会出现。但是从我的从业生涯来看，往往是会运营的，会讲故事的擅长讲故事的，能获得更高的回报，而把技术做到极致的，处于吃得好但是吃不算太饱的状态，这点从多多的技术能力和市值的关系就能看得出来。所以，多多如何把技术优势转成市值优势呢？目前看公司这块做的并不好。我是觉得它的市值配不上它的技术的。
更多缺点，欢迎各位老师傅来补充。
股市有风险，投资需谨慎。自行负责，不荐股。

第二篇：勇气与定力

炒股最难的是什么？我觉得是勇气和定力。
前几天我写了一篇文章，来介绍多氟多的缺点，为了给自己心理降温，因为我预感它要起爆了。
从17块钱，拿到22快钱并没有什么感觉，中间一开始还频繁做t，后面就不怎么动了，容易t飞，今天在25块钱的时候快拿不住了，心态有点稳不住，老想做t，25卖出的那一刻，更害怕踏空，于是赶紧又买回来，也许，根本不应该卖出。
从9.15号开始做价投，大彻大悟以来，因为缺少了大赚的经历和心理预期，以前最多也就买过一个高硼硅玻璃最高赚了40%，然后就没有更多的赚钱经历，所以心态上今天确实很忐忑。
但是从技术和市场我是非常看好的，因为电池领域的各个环节，磷酸铁锂的电解质，电解液，隔膜，铜箔，铝箔，正极，负极，还有三元电池，铅酸电池，还有储能的逆变器，bms,pcs,ems等等，多多少少都研究了一些。竞争格局相对好点的，就是六氟，经历了价格战，以及固态的隐形威胁，基本集中了，类似的还有磷化工，铬盐，以及各种小金属，都是挺不错的。要么牛逼的技术，要么牛逼的销售，要么资质或者天然的条件。更别提还有upsss氢氟酸，硼同位素，硅业子公司，你可以提它别的可能有缺点，技术上，这个公司还是挺牛的，经常性给我点惊喜，比如固态电解质。
目前大圆柱基本就是白送，没什么利润，竞争格局很差，但是市场很大，三元会被进一步压缩。还需要降本提产能后才能在这块吃上一口，目前纯抢份额。这个大圆柱做启停，动力，储能，几位一体，还是挺牛的。
目前核心的就两个点，第一，仅仅盯住六氟的涨价，我是看着从5.7到昨天的10.3的。第二，固态电解质的估值。当然，也可能随时冒出一些惊喜，那都是送的。目前已经完成我的初步估算，24块，再进入第二个估算区间，35。后续咋样，不清楚，多久走到，也不清楚。
下午和朋友聊了一下，理清楚了自己拿不住的原因，只有下跌的经验，没有大幅度上涨的经验。准备抽一万研究短线情绪和筹码流，以便于更快适应短线带来的高波动心态的影响，其余继续做长线。
投资有风险，炒股需谨慎，不作为投资建议。
第三篇：何时退出
42人赞同了该文章
这篇应该是多氟多的终结篇了。我都有点怀疑自己在这个节点写这个文章好不好。看这篇文章前，请务必回头看看我前两篇关于多氟多的文章。
这篇的核心点是，何时退出。
要回答这个问题，就必然需要结合当前的环境对企业进行估值。这个事情往往是痛苦的，因为绝大概率是错误的，对的可能是挺小的。
所以只能说，以个人的眼光角度，看待它能到多少市值。因为定了个目标后，其实非常容易打脸，但是不定目标，不结合当前的走势分析，就不知道退出时刻，其实也是一个必然需要去解决的问题。确实很痛苦。
那就不得不把这个企业给彻底拆解开来了。
以前的事就不说了，我就挑着几个核心点说吧。
先前六氟磷酸锂我们没攻克的时候，日本是卖100万一吨的。大家自己看六氟这些年的走势，在20,21年因为动力电池的爆发，到过60万一吨，而后面低的时候，最低到了4.7万一吨。而多多的成本在4.5-5之间，天际在5点多，其余的二三线估计在7，复产的话要好长时间。这个成本的核心因素是，用到的上游废料，而不是从萤石开始搞（他家也有萤石矿，还有一个买了又卖了的故事）。上游的废料来至于云天化，量大，磷伴生氟。
第一家攻克六氟的是多多。然后获得了国家科技进步二等奖，这个奖还是有技术含量的。有很多想做六氟的，做了好几年都做不出来，或者做的纯度不高，多多是定六氟标准的，这个很关键。其中一个原料，氢氟酸，超级强腐蚀性，供给半导体湿法刻蚀的，当然，用量比较小了，现在倾向于气体刻蚀。那么，这里有一个问题，就是如何存储。所以后面说到核的时候，有用到氟，那我第一反应就是，这个事，是否跟多多有关。市面上把氟玩转的玩家挺少，有制冷剂相关的几家，巨化，三美等等，而在公司亮点，敢直接以产品为招牌的，不多。这种技术能力，我当时也从其他几个元素上得到验证。
一个是硼，一个是硅。硅的信息相对较少，只在雪球上得到一点点资料，只需要看到，电子级，就够了。有一年是组上市的，后面不知道为啥又取消了。然后一个硼，这个前几天交付中核广核了。
其实这些都是公开的。这几天都吵得很火。还是来算算到底值多少钱吧。
其实综合的比单一的难估多了。这也是市场资金更看好单一体的原因，往往他们涨的更厉害。虽然多条路走路的在实际市场运营上其实对公司更好，不至于老是在生死边缘。
其他的产品我就不估算了，什么冰晶石，无水氟化铝，氟化钠，氟硅酸钠，氟硅酸钾，白炭黑，二氟磷酸锂，双氟磺酰亚胺锂，六氟磷酸钠，四氟硼酸锂，双乙二草酸硼酸锂，二氟草酸硼酸锂，电子级硝酸，电子级氨水，电子级氟化铵。围绕氟，确实是玩出了花。
上一轮六氟炒到60万，但是多多做错了战略，签的长协是定量定价的，这个导致没有赚到足够的利润，可以看到那一拨高度并不是很高。而且，那个时候，产能并不到5，我从一些老股民那里得到的信息是1.5万吨到2万吨左右。而这一波，今年30%的长协年底到期，小李这次聪明了，同等价格下才优先供应合作伙伴。如果明年稳定在15-20万，最高高度在30万以上，那么利润非常可观。6.5万吨，有1万吨需要给到氟芯大圆柱使用，那么只能卖5.5万吨，其余扩产的2万吨应该是没戏的。如果按20万算，这就110亿了，利润50亿以上，太夸张了。我觉得如果能稳定在12万就相当厉害了，这样也有30多亿。当然，其余原材料肯定也会涨，如果六氟涨的话。我们算一下现在，就算按5万来算，5.5万吨，28亿的营收，它年82多亿的营收，当时估值160左右的话，而现在算110亿+54为164亿的营收，那么其他的不管，就值328亿，差不多就是现在的价格啦。
但是，这轮无法这么估算。因为还有氟芯大圆柱，以及硼同位素，电子级氢氟酸。
电子级氢氟酸相对好算，就2万吨，一吨10万多吧。就两个多亿。你给估值也给不了。结合老股民给我的信息，当时从最高点跌到19，然后又涨回38，所以其实这个消息在上一轮已经被消化了溢价了，本轮也就无效了。我看着它前段时间才因为这个添加存储芯片概念。氢氟酸的意义主要在于情绪，以及为核能做出防腐蚀容器的贡献，对市值影响较低。半导体的用量不算特别大。增量也不算大。所以就不需要怎么估了。
下一个核心，氟芯大圆柱，说是340，这个比那些什么260-280的密度还是高不少的，比固态肯定还是小很多的，动不动就400以上，到500的说法。但是这个性价比很高，宣传的说是安全性非常高，在二三线，储能市场非常火爆，订单多的忙不过来。前段时间还爆有固态电解质，具备装车能力，这个算下来的话如果真实现，1000亿都是小case的，我们先忽略掉不考虑。
我们看一下宁王，亿纬锂能等几个头部企业，主要看产能吧。24年50gwh储能，30gwh动力。现在市值跟去年平均估值比，就算80gwh等于800亿吧，宁德去年接近500gwh, 9000亿。这个是个大概的，不是精准值，取个中间吧，如果30gwh, 那么就大概在400-500亿，而今年更紧俏，那么这个估值大概给到500-800亿。按这么算的话，多多的氟芯大圆柱如果今年达到30gwh, 估值给600亿吧，这个是给了溢价的。不给溢价那么也有300亿。
我们把刚才的328亿，加上这个300亿-600亿，那么就是600多亿到970亿左右。
最后在算一个硼。这个硼更加不好估计。因为市面上很不好算。这玩意国内没攻克之前，一顿8000万，攻克后，多多做到的成本在300-400亿左右，那么卖个500-600万一吨应该不过分吧，这个我没有直接依据，只有一个2亿多的单子的信息，推断不出来什么。另外，硼在医疗上的，也不清楚。也不知道他家这个100吨现有的产能，到底是满了还是产了多少，剩余900吨啥时候产能释放。这个估值非常不好做。但是也得硬着头皮估。我们按500万一吨，100吨现有的，5个亿而已。这块估值可以稍微给点溢价，给个5倍-10倍不过分，25-50个亿，如果后面真到1000吨，这块250-500亿的估值。这么一算，到800亿到1500亿吧。硅这块我就不估了，拿不到数据，大小姐管理的子公司。
目前我觉得相对合理的估值，大概在500-800亿，算是非常安全的估值了，超过他也不稀奇。所以如果按现在的环境，如果不发生大的变化，至少50块我是能看到的（比如乱投资，战略性错误比如造车等）。
最后补充：其实，起初，我从17块买，是分段看到24，这是第一个阶段，在20-21块洗了非常长时间，后面在28-29块洗，几乎无阻力，我在突破24后，第二阶段看到35，差不多要到这个阶段了，应该阻力也不高，所以，下一个阶段，看到50。能不能到，拭目以待。甚至我怀疑，因为现在的基本面相较于20年，有了太大的变化，手上的硬货实在太多了，这轮有可能比我想的会高一些吧。
