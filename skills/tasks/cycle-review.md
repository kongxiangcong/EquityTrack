# 周期复盘任务

1. “本周”默认覆盖请求时点所在自然周内已经证明完整的 A 股交易日；若本周尚无完整交易日，使用最近一个有证据的完整周期并明确日期。“最近五个交易日”按已证明完整会话选择，不按自然日猜测。
2. 自定义周期必须以完整会话为边界。缺少首尾会话时返回可用边界和证据缺口，不把休市日当交易日。
3. 通过唯一周期纪律复盘应用任务，从已持久化的账户快照、计划、今日复核、待处理事项、用户声明与证据缺口派生草稿。Codex 不提交分数，也不自行分类行为。
4. 默认结果包含：周期与收益口径、各持仓贡献、符合计划/触发复核/无法判断、延期或未处理事项、未记录与未核验事实、什么证据会改变结论。
5. 普通“复盘”请求直接返回不可变草稿，不要求用户确认。只有用户明确要求把复盘封存为正式历史版本时，才请求一次确认。
6. 复盘不得创造成交事实，不得把未申报视为未成交，也不得改写已确认计划或历史理由。
